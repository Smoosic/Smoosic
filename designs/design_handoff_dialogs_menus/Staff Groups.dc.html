Staff groups

Smoosic · staffGroups.vue · group builder for a large score
What changed

The current component spends three columns on Add, Create and Remove toggles, so the same question is asked three times per stave and the answer is a checkbox that means "do a thing". Here each stave has one dropdown whose options are the four operations, and the group itself owns its connector dropdown.

Reading the list

Groups are drawn, not described: the connector graphic spans its staves in the left gutter at the same weight the score will print, so the shape of the bracketing is legible without reading a single label. Ungrouped staves sit flush with an empty gutter.

Data

Connector values follow SmoSystemGroup.connectorTypes — brace 0, bracket 1, single 2, double 3 — and the dropdown writes leftConnector through setConnectorCb. The four actions map to addToGroupCb, createStaffGroupCb and removeFromGroupCb.

Four values from SmoSystemGroup.connectorTypes. Drawn in the gutter at printing weight so the list reads as a score rather than a form; all four stretch to their group's height, so the graphic is the same shape at two staves or twelve.

Open questions
  • Group names — I've shown Woodwinds, Harp, Strings. SmoSystemGroup carries text and shortText; should this dialog let you edit them, or derive a name from the staves it spans?
  • The trigger currently reads the state ("Grouped"). An alternative is a plain icon button, which is tidier but gives no read on the row.
  • Should overlapping groups be preventable in the UI, or left to overlaps() to reject on commit?
  • Nothing here reorders staves. Worth adding drag-to-reorder, or does that belong in the instruments dialog?
