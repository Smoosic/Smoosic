Dialog kit

Smoosic · Vue 3 dialog components · compact density · responsive to 768px
What I read

Built from the existing components in src/ui/components/dialogs: dialogContainer, draggableComp, numberInput, select, buttonGroup, collapsableRow and dialogButtons. Structure and prop names are unchanged; only the visual layer is new.

Assumptions

Bootstrap grid classes stay, so every row is a 12-column flex row. Tri-state buttons map to aria-pressed true / mixed / false. The backdrop is a full-viewport inert layer: transparent, pointer-events captured, focus trapped.

The system

Broadsheet, read as engraver's chrome: Source Serif 4 throughout, hairline rules instead of fills, soft 6px corners on anything clickable. Cyan is the only interactive ink; magenta appears once, as the value-changed mark. All of it lives in dialog-kit.css on the Broadsheet tokens.

3 · At 768px

Below 768px the dialog goes to calc(100vw - 24px), rows stack, labels move above their control, and the submit row becomes full-width buttons in reading order. Drag is disabled; the handle is hidden. Shown here with .dlg-stack, which mirrors the media query.

Breakpoint rules
  • Rows switch from 12-col to stacked at 768px.
  • Controls grow: 26px → 30px; hit targets in the submit row go to 44px minimum.
  • The dropdown panel becomes a bottom sheet when the list exceeds six items.
  • Grouped boxes keep their border and legend; only the internal flow changes.
  • Dialog is centred and scrolls internally; the inert layer still blocks the score.
